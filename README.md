# Blinkit Grocery Sales Analysis Dashboard

## Project Overview
This project analyzes grocery sales data to understand sales performance, product categories, customer ratings, and outlet distribution using Power BI.

## Tools & Technologies
- Power BI Desktop
- Microsoft Excel

## Dataset
- 8,523 records
- 12 columns
- Includes item type, sales, fat content, outlet size, outlet location, and ratings.

## Key Performance Indicators (KPIs)
- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Number of Items:** 8,523
- **Average Rating:** 3.9

## Analysis Performed
- Sales by item type
- Sales by fat content
- Sales by outlet size
- Sales by outlet location
- Sales by outlet establishment year
- Sales by outlet type

## Key Insights
- Fruits & Vegetables and Snack Foods are among the top-performing product categories.
- Tier 3 outlets contribute the highest sales among the location tiers.
- The dashboard provides an overview of sales performance across different outlet characteristics.

## Project Files
- `BlinkIT-analysis(1).pbix` – Power BI dashboard file.
- `Blinkit Analysis(1).pdf` – PDF version of the dashboard.

## How to View
Download the `.pbix` file and open it using Microsoft Power BI Desktop. The PDF file provides a static view of the dashboard.
